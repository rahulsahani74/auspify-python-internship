# Task 01: Password Generator

A Python-based password generator that creates strong, random passwords with customizable options. CLI-based, uses Python standard library only.

## Overview
A Python-based password generator that creates strong, random passwords with customizable options. CLI-based, uses Python standard library only.

## Features
- Custom password length
- Character set customization (letters, numbers, symbols)
- Cryptographically secure random generation
- Multiple password generation support

## Installation
No external dependencies required (uses Python standard library only).

```bash
python --version
```

## Usage
Run the application:

```bash
python main.py
```

## Testing
Run automated unit tests:

```bash
python -m unittest discover tests
```
